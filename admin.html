📡 Available Endpoints

All endpoints are integrated directly in this admin panel

GET /api/projects
Returns: Array of all projects

GET /api/services
Returns: Array of all services

GET /api/testimonials
Returns: Array of all testimonials

GET /api/stats
Returns: Website statistics (projects, clients, ROI)

POST /api/contact
Body: { name, email, message }
Returns: { success: true, message: 'Message sent successfully!' }

POST /api/admin/login
Body: { username, password }
Returns: { success: true, token: 'admin-token...' }
